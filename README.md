# 🪙 Монета — учёт личных финансов

PWA-трекер личных финансов: доходы, расходы и переводы в **рублях и юанях**, счета и кредитки
с лимитами, дерево категорий, бюджеты, аналитика и живой курс ¥→₽.
Работает офлайн, данные хранятся только на устройстве (localStorage) с резервными копиями в JSON.

---

## Возможности

| Раздел | Что умеет |
|---|---|
| **Сводка** | доходы/расходы месяца по валютам, динамика баланса за 90 дней, последние операции, бюджеты |
| **Операции** | журнал с группировкой по дням, фильтры, поиск, редактирование, двухшаговое удаление |
| **Аналитика** | пончик расходов (топ-6 + «Прочее»), крупнейшие направления, гистограмма за 6 месяцев |
| **Бюджеты** | лимиты по месяцам в ₽ и ¥, статусы «в норме / 70% / перерасход», rollup подкатегорий |
| **Счета** | наличные, дебетовые и кредитные карты, кредитный лимит, защита от овердрафта |
| **Категории** | дерево «корень → подкатегории», эмодзи, 10 цветов, траты месяца у каждой ветки |
| **Курс ¥→₽** | бесплатно и без ключа: ЕЦБ (Frankfurter) + запасной open.er-api, кэш, ручное обновление |
| **PWA** | установка на телефон/компьютер, офлайн-режим, safe-area, тактильная отдача |
| **Данные** | автосохранение в localStorage, экспорт/импорт JSON-копий, перенос между устройствами |

Быстрый ввод: **N** (или «т») — новая операция, **1/2/3** — расход/доход/перевод, **Enter** — провести, **Esc** — закрыть.

## Стек

React 18 · TypeScript · Vite · Tailwind CSS · Recharts · Lucide · Service Worker (собственный, без библиотек)

## Локальный запуск

```bash
npm install
npm run dev      # разработка: http://localhost:5173
npm run build    # продакшен-сборка в dist/
```

## 🚀 Деплой на GitHub Pages (автоматический)

Репозиторий уже содержит workflow `.github/workflows/deploy.yml`: каждый push в `main`
сам собирает проект и публикует его. Один раз настроил — дальше всё само.

### Шаг 1. Создайте репозиторий

На [github.com/new](https://github.com/new):

- **Repository name** — любой (`moneta`, `finance`, `ваш-логин.github.io`): сборка
  использует относительные пути и работает и в корне домена, и в подпапке
- **Public**, без README (он уже есть в проекте)

> ⚠️ Важно: на Pages должна попасть **сборка** (`dist`), а не исходники. Это делает
> workflow (вариант A). Если видите окно «сайт отдаёт исходники, а не сборку» —
> значит Pages показывает папку проекта: включите Source: GitHub Actions
> или загрузите содержимое `dist` (вариант B).

### Шаг 2. Загрузите проект

Скачайте проект из чата (кнопка экспорта/Download ZIP), распакуйте и в репозитории
нажмите **Add file → Upload files** — перетащите файлы проекта (вместе со скрытыми
`.github` и `.gitignore`).

> С git в терминале: `git init && git add . && git commit -m "Монета" && git remote add origin … && git push -u origin main`

### Шаг 3. Включите Pages

**Settings → Pages → Source: GitHub Actions** (Save).

### Шаг 4. Проверьте и дождитесь сборки

1. Откройте вкладку **Actions** — должен бежать workflow «Deploy to GitHub Pages».
   Зелёная галочка = сборка опубликована. Красный крестик — нажмите на него и
   посмотрите, на каком шаге упало (чаще всего помогает повторный **Re-run**).
2. Если в списке Actions пусто — файл `.github/workflows/deploy.yml` не попал в
   репозиторий: убедитесь, что скрытая папка `.github` была загружена вместе с проектом.
3. Через 2–3 минуты приложение работает на одном из адресов:

```
https://ваш-логин.github.io/            ← репозиторий «ваш-логин.github.io»
https://ваш-логин.github.io/имя-репо/   ← любой другой репозиторий
```

Каждое следующее изменение — push → автообновление сайта.

### Вариант B. Без GitHub Actions (вручную)

Если Actions недоступен: соберите проект локально (`npm ci && npm run build`)
и загрузите в репозиторий **только содержимое папки `dist`**, затем
Settings → Pages → Source: **Deploy from a branch** → `main` / `root`.

## Альтернатива: Netlify Drop

Без аккаунта и настроек: [app.netlify.com/drop](https://app.netlify.com/drop) →
перетащите **только папку `dist`** (содержимое собранного проекта) → получите
постоянную ссылку `https://имя.netlify.app`.

> На Netlify/Vercel можно выкладывать и исходники со сборкой через их CI —
> команда та же: `npm ci && npm run build`, каталог публикации `dist`.

## Установка на устройство

После первого открытия по постоянной ссылке (нужен интернет один раз):
кнопка **«Установить на телефон»** в меню «Данные и копии» → приложение на домашнем
экране, работает офлайн. На iPhone: Safari → «Поделиться» → «На экран „Домой"».

## Резервные копии

Меню «Данные и копии»: **Скачать** — JSON со всеми операциями, счетами, категориями
и бюджетами; **Восстановить** — загрузка копии (с подтверждением). Так данные
переносятся на новое устройство и страхуются от очистки браузера.

## APK (опционально)

Для публикации в Google Play: [pwabuilder.com](https://www.pwabuilder.com) →
вставьте ссылку на задеплоенное приложение → **Package for Android** → подписанный APK.
Для личного пользования APK не нужен — PWA делает всё то же без подписей и переустановок.
